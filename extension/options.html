Groq 받아쓰기

노트북에서 음성 인식 모델을 실행하지 않습니다. 압축 음성을 Groq로 전송하며, 모델은 whisper-large-v3-turbo를 사용합니다.

Groq Free 계정에서 API 키 발급 후 아래에 저장하세요. 유료 플랜의 키는 비용이 발생할 수 있습니다.

새 키를 입력하고 연결 테스트를 누르면 그 키를 먼저 저장한 뒤 확인합니다. 음성 전송 동의는 ‘키·동의 저장’으로 별도 저장하세요. 연결 프로그램 오류가 나면 설치 폴더의 진단 도구로 설치 상태를 확인할 수 있습니다.

무료 한도는 조직별로 적용됩니다. 현재 공개 기본 한도는 음성 2시간/시간, 8시간/일이며 계정의 실제 한도가 우선합니다. 한도 초과 시 대기열을 유지하고 재개합니다. 연결 테스트는 모델 목록만 확인하며 음성을 전송하지 않습니다.

Google Drive 백업 선택

켜면 HTML 다운로드가 끝난 뒤 같은 파일을 내 Drive의 KLAS요약 폴더에 백업해요. 대본·슬라이드가 포함된 HTML이 Google로 전송됩니다. 연결하지 않아도 다운로드할 수 있어요.

연결 안 됨

Google Drive 연결이 준비된 설치본으로 업데이트하면 계정을 연결할 수 있어요. HTML 다운로드는 그대로 사용할 수 있습니다.

연결 해제·로컬 기록 삭제 시 Drive 백업은 남아요. 공개 공유 링크는 만들지 않습니다.
