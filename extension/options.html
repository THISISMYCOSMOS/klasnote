Groq 받아쓰기

노트북에서 음성 인식 모델을 실행하지 않습니다. 압축 음성을 Groq로 전송하며, 모델은 whisper-large-v3-turbo를 사용합니다.

Groq Free 계정에서 API 키 발급 후 아래에 저장하세요. 유료 플랜의 키는 비용이 발생할 수 있습니다.

무료 한도는 조직별로 적용됩니다. 현재 공개 기본 한도는 음성 2시간/시간, 8시간/일이며 계정의 실제 한도가 우선합니다. 한도 초과 시 대기열을 유지하고 재개합니다. 연결 테스트는 모델 목록만 확인하며 음성을 전송하지 않습니다.
