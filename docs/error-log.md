## A. 설치 · 크롬 등록

**A1. install.cmd 실행 시 `'…'은(는) 내부 또는 외부 명령… 이 아닙니다` 반복 → 연결 테스트에서 `Specified native messaging host not found`** — `재발 중` (10/12 지인 제보)
- 증상: Node가 설치돼 있어도 install 실행 창에 깨진 글자(`'Node.js'`, `'b'`, `'댐뀛:'` 등)를 명령으로 실행하려는 오류가 줄줄이 뜸. 확장은 올라가지만 연결 테스트가 host not found.
- 원인(재현으로 확인): 저장소와 공개 ZIP 0.1.5의 `install.cmd`·`start.cmd`가 **LF 줄바꿈**이다(`git ls-files --eol` → `i/lf`). `.gitattributes`에는 `*.command`·`*.sh`만 있고 `*.cmd` 규칙이 없다. cmd.exe는 LF만 있는 배치 파일에서 `chcp 65001` 뒤 한글(UTF-8) 줄을 잘못 끊어 읽는다. 이 PC에서 LF 사본을 돌리면 같은 종류의 오류가 나고, **설치 단계(`node scripts\setup.mjs`)는 아예 실행되지 않았다**. 그래서 호스트가 레지스트리에 등록되지 않아 host not found가 뜬다. CRLF 사본은 정상 실행됐다. 이 PC 작업본만 git이 CRLF로 바꿔 줘서 개발 중에는 드러나지 않았다.
- 해결 방향: `.gitattributes`에 `*.cmd text eol=crlf`를 추가하고, `build-package.mjs`가 `.cmd`를 CRLF로 넣는지 확인한 뒤 ZIP을 다시 만들기.
- 지금 겪는 사용자 우회책: 압축 푼 `klasnote` 폴더에서 명령 프롬프트를 열고 `node scripts\setup.mjs --install-only` 실행 → 크롬에서 확장 새로고침.
