# KLAS 강의 요약

본인이 한 번 열어 본 강의를 개인 복습용 HTML로 정리하는 Chrome 확장 프로그램입니다. 받아쓰기는 PC에서 Whisper로 처리합니다. AI 요약을 선택하면 군말을 줄인 대본과 일부 슬라이드를 본인의 Claude Code 또는 Codex 계정으로 전송합니다. API 키는 사용하지 않습니다.

## 설치

Windows와 Chrome 116 이상, Node.js가 필요합니다. AI 기능은 Claude Code 또는 Codex CLI를 설치하고 본인의 계정으로 로그인한 경우 사용할 수 있습니다. 로컬 전용 모드는 AI CLI 없이 사용할 수 있습니다.

```powershell
cd "$env:USERPROFILE\OneDrive\문서\klas-summarizer"
npm ci
node scripts/vendor.mjs
.\install.ps1
```

이미 vendor 파일이 있으면 의존성 설치와 vendor 복사를 반복할 필요가 없습니다. 호스트는 현재 사용자 `%LOCALAPPDATA%\KlasSummarizer`에 복사되고 HKCU에 등록됩니다. 관리자 권한은 필요하지 않습니다. 설치 시 Node 절대 경로를 고정하므로 Node를 옮기거나 제거했다면 다시 설치하세요.

Chrome `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드**하여 이 프로젝트의 `extension` 폴더를 선택합니다. 고정 확장 ID는 `klihhclhnhhmldcbnkpampimkjafmbdm`입니다. 소스가 바뀌면 확장 관리 화면에서 새로고침하고 KLAS 페이지도 새로고침하세요. `tools`와 `tmp`는 개발 검증용이며 확장에 포함하지 않습니다.

## 사용

처음에 로컬 전용 또는 AI 모드를 선택합니다. 이후 확장 아이콘이나 KLAS의 **클라스노트 상태 표시**을 눌러 오른쪽 패널에서 진행 상황을 봅니다. 사용 방법은 패널의 도움말에서, 설정은 설정 버튼에서 엽니다.

1. KLAS 온라인 강의 목록에서 강의를 직접 한 번 엽니다. 확장은 강의 창을 대신 열지 않습니다.
2. 해당 강의의 **지금 요약**을 누릅니다. 받아쓰기·슬라이드 처리가 끝나면 같은 패널에 확인 화면이 표시됩니다. **강의 목록으로**를 누르면 돌아갑니다. 패널을 열 수 없는 경우에는 확인 탭을 엽니다.
3. 확인하면 개인 HTML이 `다운로드/KLAS요약/<과목>/...html`에 저장됩니다. 원문과 슬라이드는 로컬 파일에 포함됩니다.

강의별 **자동 처리**는 기본 OFF입니다. ON이면 다음에 그 강의를 직접 열 때 처리합니다. AI 전송 전 확인은 기본 ON이며, 사용자가 이 설정을 끈 경우에만 자동 AI 전송합니다. 저장된 AI 요약은 재사용하며 새로 요약을 명시적으로 요청한 경우에만 재호출합니다. 모델·계정 설정을 바꿔도 기존 저장 요약은 그대로 재사용됩니다.

요청 중지로 이미 사용한 AI 사용량을 되돌릴 수는 없습니다. 받아쓰기는 현재 구간이 끝난 뒤 멈출 수 있어 즉시 중지되지 않을 수 있습니다. 모델을 처음 받거나 로드하는 중에는 중지에 더 시간이 걸립니다.

## 요약 규칙

- 전체 개요 3~5문장, 슬라이드마다 핵심 최대 3개와 보충 설명 1문장, 시험 점검 항목 3~7개.
- 원문을 AI가 다시 쓰지 않습니다. 확실한 받아쓰기 오류의 교정 목록만 최대 40개 받아 원문에 표시합니다.
- 절약/표준/상세 프리셋의 전송 이미지 상한은 10/25/60장입니다. 발화가 없는 슬라이드는 근거 없이 내용을 만들지 않도록 지시합니다.
- AI와 음성인식은 틀릴 수 있습니다. 토큰 추정도 휴리스틱입니다. HTML의 원문·슬라이드와 비교하여 확인하세요.

Claude 기본 모델은 Sonnet이며 Haiku/Opus를 선택할 수 있습니다. Codex 모델은 `gpt-5.6-terra`로 고정합니다. 이전 실측에서 Codex의 호출 고정 입력량이 Claude보다 높았습니다. 추정에는 이 차이를 반영하지만 현재 계정의 남은 사용량이나 호출 성공을 보장하지는 않습니다.

## 동작 범위와 자원 사용

페이지 스크립트는 KLAS 온라인 강의 목록과 KWCommons 강의 플레이어 URL에서만 실행됩니다. 패널·설정에서 저장 목록을 보는 것만으로 받아쓰기 엔진을 시작하지 않습니다. 강의 처리는 한 번에 하나, 120초 구간 단위로 수행합니다. Whisper는 모델 변경 시와 처리 종료 후 30초 유휴 상태에 메모리를 해제합니다. 다운로드한 모델의 브라우저 캐시는 남겨 재다운로드를 줄입니다.

강의 목록의 조작 UI는 기존 보기 셀 안에 별도 Shadow DOM으로 붙입니다. 기존 보기 버튼, Vue 데이터, 동영상 제어, 출석·인증·진도 처리는 변경하지 않습니다. 실제 Chrome에서 두 확장을 함께 등록·활성화한 상태를 확인했습니다. 강의 화면에서의 실제 동시 작동은 아직 검증하지 않았습니다. 모션은 패널·설정에만 표시하며 끄기와 숨김·동작 줄이기를 지원합니다.

WebGPU를 쓸 수 없는 offscreen 환경에서는 확장 내부 처리 탭을 생성할 수 있습니다. 강의 플레이어가 아닌 로컬 처리 탭입니다. WASM 대체 경로와 전체 강의 처리의 메모리 최대치는 이번 인계에서 실측하지 않았습니다.

## 개인정보·이용 조건

강의·대본·슬라이드·요약 기록은 이 브라우저의 IndexedDB에 저장합니다. 영상과 모델을 받기 위한 네트워크 요청은 있습니다. AI 모드에서는 대본과 선택한 슬라이드가 본인의 AI 서비스로 전송되고 해당 서비스의 처리 정책을 따릅니다. 공유 서버·다른 학생과의 공동 캐시·HTML 공유 기능은 없습니다.

개인 이용이라고 모든 다운로드·외부 AI 전송이 자동으로 허용되는 것은 아닙니다. 공개 KLAS 화면과 [원격수업 운영 규정](https://rule.kw.ac.kr/lmxsrv/law/lawFullContent.do?SEQ=92&SEQ_HISTORY=631)에서 학생 AI 요약에 관한 명시적 허용·금지를 확인하지 못했습니다. 강의별 지침은 별도 확인이 필요합니다. [저작권법 제30조](https://www.law.go.kr/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900604433)의 사적 복제 요건과 [제35조의5](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=05&joNo=0035&lsiSeq=283335&urlMode=lsScJoRltInfoR)의 공정이용 판단을 무조건적인 허가로 해석하지 않습니다. HTML에는 원문·슬라이드가 포함되므로 타인 배포를 제품 기능으로 지원하지 않습니다.

우니 PNG는 설치 시 함께 사용할 수 있도록 저장소에 포함했습니다. 학교 사용 승인을 받은 상태는 아닙니다. 이미지 권리와 출처는 extension/assets/README.md에 적었습니다. [학교 공식 마스코트 안내](https://news.kw.ac.kr/mascot/mascot.html)에 따른 사용 신청과 2차 가공 심의는 별도입니다. 준비한 신청 문안과 메일 양식은 Codex 작업 폴더의 outputs에 있습니다. 메일은 보내지 않았습니다.

## 삭제

로컬 강의 기록은 설정에서 강의별로 삭제합니다. 진행 중인 받아쓰기·AI 요청은 멈춘 뒤 삭제하세요. 이미 다운로드한 HTML은 브라우저 저장소와 별개입니다.

```powershell
.\uninstall.ps1 -WhatIf   # 대상 확인만
.\uninstall.ps1          # 현재 사용자 호스트 등록과 설치 파일 제거
```

Chrome 확장은 확장 관리 화면에서 제거합니다. 호스트 제거 스크립트는 브라우저 강의 기록을 지우지 않습니다.

## 검증 상태

`npm test`: 16개 로컬 테스트 통과. 메시지 발신자·동의/열람 조건·확인 티켓·중복/재전송·캐시·취소/재시도·파일명·AI JSON과 실제 네이티브 바이너리 프로토콜의 감지/잘못된 요청 거부를 확인했습니다. 유료 AI 호출은 테스트에 없습니다.

localhost 합성 브라우저 검증 8개 통과: IndexedDB의 강의/대본/이미지/요약 저장, 이미지 crop·전송 묶음·토큰 추정, HTML escaping/CSP/교정, 일괄 삭제. 현재 사용자 호스트 설치와 설치된 launcher의 CLI 감지도 확인했습니다.

실제 Google Chrome 154의 별도 프로필에서 `KLAS 강의 요약`과 `KLAS Helper 2.2.1` 등록·활성화, 서비스 워커 실행, 기본 저장소 초기화를 확인했습니다. 새 sidePanel 권한·경로 등록과 재연결 후 저장소 유지를 확인했습니다. 실제 Chrome의 패널 시각 동작은 미검증입니다. Codex 작업 폴더 outputs의 `KLAS_Chrome_실행.cmd`는 실행할 때마다 개발 확장을 연결합니다. CDP 등록이 재시작 때 해제되는 Chrome 동작에 맞춘 실행 환경이며, 기존 기본 Chrome 프로필에는 설치하지 않았습니다. 일반 Chrome에 영구 등록하려면 위의 압축해제 확장 설치 절차를 사용합니다.

**미검증**: 실제 Chrome 설치형 메시지·다운로드 E2E, 실제 플레이어 iframe URL의 최종 형태, 클라스헬퍼 동시 사용, 강의 한 편 전체 처리, 시청 중 GPU 부하/최대 메모리, 이번 변경 후 실제 AI 전송량 대비 추정 오차. 기존 HANDOFF의 실측은 이전 spike 증거이며 이번에 모두 재측정한 결과가 아닙니다.


패널은 확장 아이콘 또는 상태 표시를 눌렀을 때 열립니다. 처리 완료 시 자동으로 열지 않습니다. KLAS 상단에 독립 상태 버튼을 두고, 상단 영역을 찾지 못하면 오른쪽 아래에 표시합니다. 상태 표시는 처리 중/확인 필요/오류/대기만 조회하며 요약 엔진을 시작하지 않습니다. KLAS Helper 전역 변수·스타일·이벤트를 사용하지 않습니다.
